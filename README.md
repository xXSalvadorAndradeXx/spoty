# Ronin · OST

Extrae toda la carpeta y abre index.html. No requiere servidor ni dependencias.

Selecciona cualquiera de las diez pistas. Siguiente y anterior reproducen la pista inmediatamente, aunque el reproductor estuviera pausado. Al finalizar una pista se reproduce la siguiente; al terminar la última se detiene salvo que actives repetir playlist.

Se conservan los MP3 originales y el diseño.
